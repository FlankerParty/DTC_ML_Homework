# 项目概览

根据汽车的品牌、车型、年份、发动机参数、油耗、类别等特征，预测汽车价格 `MSRP`。

这是一个典型的**回归问题（Regression）**：

$$
g(X) \approx y
$$

其中：

- `X`：特征矩阵
- `y`：目标变量，这里是汽车价格
- `g`：模型，这里使用线性回归

整个项目的核心流程：

```text
读取数据
→ 数据清洗
→ EDA
→ 处理目标变量
→ Train / Validation / Test 划分
→ 构造特征矩阵
→ 训练线性回归
→ RMSE 验证
→ 特征工程
→ 类别变量编码
→ 正则化
→ 超参数调优
→ Train + Validation 重训
→ Test 最终评估
→ 对新样本预测
```

# 线性回归原理与实现

对于一个样本：

$$
g(x_i)
=
w_0
+
w_1x_{i1}
+
w_2x_{i2}
+\cdots+
w_nx_{in}
$$

也可以写成：

$$
g(x_i)=w_0+\sum_{j=1}^{n} w_jx_{ij}
$$

其中：

- $w_0$：偏置项 / 截距
- $w_j$：第 `j` 个特征的权重
- $x_{ij}$：第 `i` 个样本的第 `j` 个特征

## 最直接的实现

```python
def linear_regression(xi):
    n = len(xi)
    pred = w0

    for j in range(n):
        pred = pred + w[j] * xi[j]

    return pred
```

本质就是：

```text
偏置
+ 特征1 × 权重1
+ 特征2 × 权重2
+ ...
```

---

## 点积形式

线性回归中的求和：

$$
\sum_{j=1}^{n}x_{ij}w_j
$$

实际上就是两个向量的点积：

$$
x_i^T w
$$

因此：

$$
g(x_i)=w_0+x_i^Tw
$$

手写点积：

```python
def dot(xi, w):
    n = len(xi)
    res = 0.0

    for j in range(n):
        res += xi[j] * w[j]

    return res
```

于是：

```python
def linear_regression(xi):
    return w0 + dot(xi, w)
```

NumPy 中可以直接：

```python
xi.dot(w)
```

---

## 将偏置并入权重向量

可以人为增加一个恒为 `1` 的特征：

$$
x_{i0}=1
$$

于是：

$$
w_0x_{i0}=w_0
$$

这样就可以把偏置也放进点积：

```python
xi = [1] + xi
w_full = [w0] + w
```

从而：

$$
g(x_i)=x_i^Tw
$$

这个技巧后面用于构造正规方程。

---

## 矩阵形式

如果有很多样本，可以把每个样本作为一行：

$$
X=
\begin{bmatrix}
x_1^T\\
x_2^T\\
\vdots\\
x_m^T
\end{bmatrix}
$$

一次性预测所有样本：

$$
Xw \approx y
$$

NumPy：

```python
y_pred = X.dot(w)
```

因此线性回归从程序角度可以理解为：

```text
单样本：向量 · 权重
多样本：矩阵 · 权重
```

---

## 正规方程

模型训练的目标是找到合适的 `w`：

$$
Xw \approx y
$$

由于 `X` 通常不是方阵，不能直接：

$$
w=X^{-1}y
$$

对等式两边左乘 $X^T$：

$$
X^TXw=X^Ty
$$

其中：

$$
X^TX
$$

称为 **Gram Matrix（格拉姆矩阵）**。

如果它可逆：

$$
\boxed{
w=(X^TX)^{-1}X^Ty
}
$$

这就是线性回归的**正规方程（Normal Equation）**。

$(X^T X)$ 可逆 ⇔ $(X)$ 的各个特征列线性无关，也就是$(X)$ 满列秩。

### NumPy 实现

```python
def train_linear_regression(X, y):
    ones = np.ones(X.shape[0])
    X = np.column_stack([ones, X])

    XTX = X.T.dot(X)
    XTX_inv = np.linalg.inv(XTX)

    w_full = XTX_inv.dot(X.T).dot(y)

    return w_full[0], w_full[1:]
```

代码解释：

```python
ones = np.ones(X.shape[0])
```

创建全 1 列，用于偏置项。

```python
X = np.column_stack([ones, X])
```

变成：

```text
[1, x1, x2, ...]
```

```python
XTX = X.T.dot(X)
```

计算：

$$
X^TX
$$

```python
XTX_inv = np.linalg.inv(XTX)
```

求逆。

```python
w_full = XTX_inv.dot(X.T).dot(y)
```

对应：

$$
(X^TX)^{-1}X^Ty
$$

最后：

```python
w0 = w_full[0]
w = w_full[1:]
```

## RMSE

回归模型需要一个客观指标。

RMSE：

$$
\boxed{
RMSE=
\sqrt{
\frac{1}{m}
\sum_{i=1}^{m}
(g(x_i)-y_i)^2
}
}
$$

计算过程：

```text
预测值 - 真实值
→ 平方
→ 求平均
→ 开平方
```

实现：

```python
def rmse(y, y_pred):
    se = (y - y_pred) ** 2
    mse = se.mean()
    return np.sqrt(mse)
```

RMSE 越小越好。

平方的作用：

- 正负误差不会互相抵消
- 大误差受到更强惩罚

开平方后，RMSE 与目标变量处于相同尺度。

本项目的 `y` 是 `log1p(price)`，因此这里的 RMSE 也是**对数价格空间**中的误差。

---

## 统一特征准备流程

训练集、验证集、测试集必须采用完全相同的特征处理流程。

因此把处理逻辑封装进：

```python
def prepare_X(df):
    df_num = df[base]
    df_num = df_num.fillna(0)
    X = df_num.values
    return X
```

使用：

```python
X_train = prepare_X(df_train)
w0, w = train_linear_regression(X_train, y_train)

X_val = prepare_X(df_val)
y_pred = w0 + X_val.dot(w)

score = rmse(y_val, y_pred)
```

核心原则：

```text
训练时怎么处理数据
预测时就必须怎么处理数据
```

否则模型收到的特征定义会不一致。

---

## Validation 的意义

不能只在训练集上计算 RMSE。

正确流程：

```python
X_train = prepare_X(df_train)
w0, w = train_linear_regression(X_train, y_train)

X_val = prepare_X(df_val)
y_pred = w0 + X_val.dot(w)

rmse(y_val, y_pred)
```

Validation 用于判断：

- 新特征是否有用
- 某种预处理是否有用
- 正则化参数是否合适
- 模型是否开始过拟合

Test 在这些选择完成前应保持不动。

# 特征工程与类别变量

年份 `year` 本身可以使用，但：

```text
2017
2012
2005
```

不如：

```text
0 年
5 年
12 年
```

具有直接语义。

数据采集于 2017 年，因此：

```python
df["age"] = 2017 - df.year
```

加入 `prepare_X`：

```python
def prepare_X(df):
    df = df.copy()

    features = base.copy()

    df["age"] = 2017 - df.year
    features.append("age")

    df_num = df[features]
    df_num = df_num.fillna(0)

    return df_num.values
```

## 为什么要 `df.copy()`

如果直接：

```python
df["age"] = ...
```

函数会修改调用者传入的原始 DataFrame。

使用：

```python
df = df.copy()
```

可以保证数据准备函数没有意外副作用。

## 为什么要 `base.copy()`

不要：

```python
features = base
features.append("age")
```

因为 `features` 和 `base` 会引用同一个列表。

应：

```python
features = base.copy()
```

否则每次调用函数都可能继续修改全局 `base`。

加入 `age` 后，验证 RMSE 从约：

```text
0.76
```

降低到约：

```text
0.52
```

说明 `age` 是非常有效的特征。

## One-Hot Encoding

线性回归只能处理数值，因此需要把类别转换成二进制特征。

例如：

```text
number_of_doors
```

转换为：

```text
num_doors_2
num_doors_3
num_doors_4
```

逻辑：

```python
(df.number_of_doors == 2).astype(int)
```

布尔值：

```text
True / False
```

通过：

```python
.astype(int)
```

转换为：

```text
1 / 0
```

### 示例

```python
for v in [2, 3, 4]:
    feature = "num_doors_%s" % v
    df[feature] = (df.number_of_doors == v).astype(int)

```

# 数值稳定性与正则化

加入大量类别特征后，模型可能突然出现：

```text
RMSE ≈ 41
权重 ≈ 10^15
```

原因不是“类别特征一定不好”，而是正规方程中的：

$$
(X^TX)^{-1}
$$

出现了数值不稳定。

## 奇异矩阵

如果两个特征列完全重复，或者一个特征可以由其他特征线性组合得到，那么：

$$
X^TX
$$

可能不可逆。

例如：

```text
column_2 == column_3
```

此时矩阵是 singular matrix。

## 近似共线

现实数据中可能不是完全重复，而是：

```text
5
5.00000001
```

这种极小差异可能让矩阵在数值上“勉强可逆”，但逆矩阵中的值会非常巨大。

结果：

```text
很大的正权重
+
很大的负权重
```

互相抵消，使模型极其不稳定。

---

## 正则化

解决方法：在 Gram Matrix 的对角线上加一个小值。

原本：

$$
X^TX
$$

修改为：

$$
X^TX+rI
$$

其中：

- $I$：单位矩阵
- $r$：正则化参数

NumPy：

```python
XTX = XTX + r * np.eye(XTX.shape[0])
```

它可以改善矩阵可逆性，并限制权重变得过大。

### 正则化训练函数

```python
def train_linear_regression_reg(X, y, r=0.001):
    ones = np.ones(X.shape[0])
    X = np.column_stack([ones, X])

    XTX = X.T.dot(X)
    XTX = XTX + r * np.eye(XTX.shape[0])

    XTX_inv = np.linalg.inv(XTX)
    w_full = XTX_inv.dot(X.T).dot(y)

    return w_full[0], w_full[1:]
```

与普通版本相比，关键只多了一行：

```python
XTX = XTX + r * np.eye(XTX.shape[0])
```

本项目中，加入正则化后验证 RMSE 从异常的约：

```text
41
```

恢复到约：

```text
0.46
```

---

## 正则化参数调优

`r` 太小：

- 可能仍然存在数值不稳定

`r` 太大：

- 权重被压得太厉害
- 模型可能欠拟合

因此在 Validation 上尝试多个值：

```python
for r in [0.0, 0.00001, 0.0001, 0.001, 0.1, 1, 10]:
    X_train = prepare_X(df_train)
    w0, w = train_linear_regression_reg(X_train, y_train, r=r)

    X_val = prepare_X(df_val)
    y_pred = w0 + X_val.dot(w)

    score = rmse(y_val, y_pred)

    print(r, w0, score)
```

最终选择：

```python
r = 0.001
```

Validation RMSE 约为：

```text
0.4608
```

这里 `r` 属于**超参数（Hyperparameter）**：

- `w` 是模型从训练数据学习到的参数
- `r` 是训练之前人为设定并通过 validation 选择的超参数

# 关键函数与核心总结

## RMSE

```python
def rmse(y, y_pred):
    return np.sqrt(((y - y_pred) ** 2).mean())
```

## 普通线性回归训练

```python
def train_linear_regression(X, y):
    ones = np.ones(X.shape[0])
    X = np.column_stack([ones, X])

    XTX = X.T.dot(X)
    XTX_inv = np.linalg.inv(XTX)

    w_full = XTX_inv.dot(X.T).dot(y)

    return w_full[0], w_full[1:]
```

## 带正则化的训练

```python
def train_linear_regression_reg(X, y, r=0.001):
    ones = np.ones(X.shape[0])
    X = np.column_stack([ones, X])

    XTX = X.T.dot(X)
    XTX = XTX + r * np.eye(XTX.shape[0])

    XTX_inv = np.linalg.inv(XTX)
    w_full = XTX_inv.dot(X.T).dot(y)

    return w_full[0], w_full[1:]
```

## 最重要的理解

### 线性回归本质

单样本：

$$
g(x_i)=w_0+x_i^Tw
$$

多样本：

$$
g(X)=Xw
$$

训练：

$$
w=(X^TX)^{-1}X^Ty
$$

正则化后：

$$
w=(X^TX+rI)^{-1}X^Ty
$$

### 数据集三个部分不能混用

```text
Train
→ 学参数 w

Validation
→ 选特征、选 r、调模型

Test
→ 最终一次评估
```

不能根据 Test 结果不断改模型，否则 Test 实际上就变成了 Validation。

### 特征工程可能比换模型更重要

本项目只增加：

```python
age = 2017 - year
```

RMSE 就从约：

```text
0.76
```

降到约：

```text
0.52
```

说明好的特征表达可以显著提升简单模型。

### 类别变量必须数值化

典型方法：

```text
类别
→ One-Hot Encoding
→ 0/1 特征
```

### 更多特征不一定更好

增加大量相关或重复特征可能导致：

```text
共线性
→ XᵀX 接近奇异
→ 逆矩阵巨大
→ 权重爆炸
→ 模型崩坏
```

正则化用于提高数值稳定性并限制权重。

### 数据处理必须统一

`prepare_X` 的价值不只是“少写代码”，而是保证：

```text
Train
Validation
Test
线上新样本
```

全部经过相同的特征构造过程。

这实际上已经是在建立最基础的 **ML preprocessing pipeline** 思维。
